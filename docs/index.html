ParentReport

A school reporting portal for Pakistani schools and academies, with private student report cards and a WhatsApp notification workflow.

Built with React, TypeScript, FastAPI, and PostgreSQL. The local demo uses fictional school records and simulated WhatsApp delivery.

View source and run the demo

From class roster to private report card

School admins

Set up classes, assign teachers, and control class access.

Class teachers

Import student rosters, enter marks, and publish assessment reports.

Parents and guardians

View linked children’s results in a mobile workspace with English and Roman Urdu controls.

Backend and WhatsApp workflow

FastAPI sessions and PostgreSQL row-level policies keep class and guardian access scoped. The notification queue checks guardian verification and consent before dispatch. Signed Meta callbacks update delivery status.

The live WhatsApp pilot requires Meta credentials and production setup. The repository includes local setup instructions and tests for the mocked delivery flow.
